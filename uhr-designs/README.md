# Uhr-Designs zum Nachladen

Diese Schriften laedt **Atelier Minimal** unter Einstellungen → Uhr → „Weitere Uhr-Designs laden“ nach.
`index.json` listet sie auf (id, Name, Datei).

Alle Schriften stehen unter der SIL Open Font License 1.1 (siehe `../FONTS-LICENSE.txt`) und stammen von Google Fonts.
